- 대상 폴더: `outputs/{02_features,03_screening,04_overlap,05_visualize}/P2_phase/`
- feature 1종: `phase_vel_std`  (**제안 2종 중 PLV 는 기각** — 2.3절)
- 작성일: 2026-10-28 / 근거 실행: 창 64·144·256, seed 0–4, fold 6개

## 1. 방법론 — 무엇을 재는가

신호를 해석적 신호(analytic signal)로 바꿔 **순간 위상**을 뽑고, 그 위상이 얼마나 고르게
돌아가는지를 본다. 진폭이 아니라 **위상의 규칙성**을 재므로, "정상 상태는 일정한 주기로 돌고
과도 상태는 그 리듬이 깨진다"는 가정을 직접 검사한다.

| 제안 feature | 정의 | 직관 |
|---|---|---|
| **Instantaneous phase velocity** (채택 → `phase_vel_std`) | `std(diff(unwrap(angle(hilbert(x)))))` | 위상이 한 샘플마다 얼마나 일정하게 전진하는가. 작으면 규칙적인 진동 |
| Phase-Locking Value (**기각**) | 여러 주기에 걸친 위상 고정 정도 | 2.3절 참조 |

## 2. 어떻게 적용했는가

### 2.1 산출 절차 (`code/02_features.py`)

```
e(t) = Film Tension #1 (kg) − Film-Tension Setting Value (kg)
  → 시점 t 에서 뒤쪽(causal) 창 x = e[t−W+1 … t]
  → 창 내 평균 제거  x_c = x − mean(x)       (DC 가 위상을 지배하지 않도록)
  → Hilbert 변환     a = hilbert(x_c)         ★ 창 단위로 건다 (causal 유지)
  → 위상 펼치기      φ = unwrap(angle(a))     ★ 필수 (2.2절)
  → phase_vel_std = std(diff(φ), ddof=1)      단위 rad/sample
```

- **창 단위 Hilbert**: 전체 run 에 한 번 거는 방식은 미래 시점을 쓰게 되어 causal 하지 않다.
  창마다 따로 걸어 인과성을 지킨다. 대신 창 양끝에서 edge effect 가 생긴다 — 창 144(15.7 s)는
  짧은 창보다 edge 비중이 작아 이 영향이 덜하다.
- **테이퍼를 쓰지 않는다**. Hann 을 곱하면 창 양끝 진폭이 0으로 눌려 위상이 왜곡된다
  (스펙트럼 계열 P1 과 다른 점).
- 단위는 **rad/sample** 이다. 초 단위로 바꾸려면 `÷ 0.109 s`.

### 2.2 `unwrap` 은 선택이 아니라 필수다

제안 코드의 `np.std(np.diff(np.angle(...)))` 는 위상이 `−π → +π` 로 감길 때 생기는 **2π 점프를
변동으로 잘못 센다.** 실측(창 144): 점프 11회, `std` **1.609** → `unwrap` 적용 시 **0.278**.
5.8배 차이다. 점프 횟수는 신호 내용이 아니라 위상 원점 위치에 따라 달라지므로, 고치지 않으면
feature 가 사실상 잡음이 된다.

### 2.3 PLV 를 기각한 근거 (계획 3.1절)

| # | 근거 |
|---|---|
| 1 | **위상 고정은 여러 주기를 봐야 성립한다.** 회전 외란 주기는 `C/V = 783.5 mm / V` 이고, 창 144는 V=50 에서 **정확히 1주기**뿐이다 (V=200 에서도 4.01주기). 저속 조건에서 PLV 가 정의되지 않는다 |
| 2 | 창 144 + backfill 이면 과도 구간 내부가 상수다(한계 L2). **transient 에서 위상 고정을 측정할 대상 자체가 없다** |

창 144 내 회전 주기 수: V=50 **1.00** / 75 1.50 / 100 2.00 / 125 2.50 / 150 3.00 / 175 3.51 / 200 4.01

### 2.4 임의로 정한 값

| 값 | 설정 | 근거 |
|---|---|---|
| 창 단위 Hilbert | 창마다 따로 | causal 유지. 전체 run 에 걸면 미래를 본다 |
| 테이퍼 | 없음 | 포락선·위상 왜곡 방지 |
| 포함 여부 | 포함하되 한계 기록 | 승인 #11 — 광대역 신호의 Hilbert 위상은 물리적 의미가 약하다 |

## 3. 결과 해석

### 3.1 단독 성능은 16개 중 최상위권이다

| | D(W64) | D(W144) | D(W256) | T(tension) | T(final_test) |
|---|---|---|---|---|---|
| `phase_vel_std` | 0.854 | 0.941 | 0.936 | **0.718** | **0.867** |

- **T(tension) 0.718 은 16개 feature 중 1위다.** T(final_test) 0.867 은 2위 (1위 `half_mean_diff` 0.904).
- 기준점 F0 의 T(tension) 0.608 / T(final_test) 0.541 을 양쪽 모두 크게 넘는다.
- 효과크기 Cohen's d = **−2.57** 로 16개 중 2위. 부호가 음수 = **transient 쪽이 작다**.

**방향이 직관과 반대다.** "과도에서 리듬이 깨지므로 위상속도 변동이 커진다"가 아니라, 과도 구간은
**느린 단방향 처짐**이라 위상이 오히려 더 고르게 전진한다. steady 구간이 여러 주파수가 섞인
광대역 진동이라 위상속도 변동이 크다. P1 의 방향 수정(3.1절)과 같은 물리적 그림이다.

### 3.2 그런데 F0 에 더하면 이득이 없다 — 이 계열의 역설

| 추가 | ΔT(tension) | ΔT(final_test) |
|---|---|---|
| `phase_vel_std` | **−0.0022** | +0.0000 |

단독으로는 F0 를 압도하는데 **F0 에 더하면 아무 이득이 없다.** 해석:

- `phase_vel_std` 가 담은 정보가 `movstd`·`movslope` 와 **상당 부분 겹친다**
  (`_cross/corr_matrix_W144.csv` 로 확인).
- 후단이 **diag GMM** 이라 차원 간 상관을 모델링하지 못한다. 중복된 축을 하나 더 넣으면
  그 방향의 분산만 두 번 세는 꼴이 되어 군집 경계가 오히려 나빠진다.

→ **"단독 대체" 와 "추가" 는 다른 질문이다.** `phase_vel_std` 는 F0 를 **대체**할 후보이지
F0 에 **덧붙일** 후보가 아니다. 이 구분을 B 로 넘길 때 반드시 적어야 한다.

### 3.3 조건 정보는 중간 수준이다

| | 상태 AUROC | 속도 조건 AUROC | steady 구간만 | 속도 분류 정확도 (우연 0.143) |
|---|---|---|---|---|
| `phase_vel_std` | 0.941 | 0.645 | 0.668 | 0.282 |

16개 중 중간(9위권). 스펙트럼 계열(`spec_centroid` 0.739)보다 조건 의존이 낮고,
진폭 계열과 비슷한 수준이다.

더 중요한 것은 **상태 평균차의 조건 간 변동계수 `abs_cv` = 0.529 로 16개 중 2번째로 작다**는
점이다 (1위 `movmean_abs_e` 0.340, 3위 `hurst` 0.595). **상태 신호의 크기가 속도에 따라 거의
변하지 않는다**는 뜻이라, 조건 불변 설계와 가장 잘 맞는 feature 중 하나다.

### 3.4 창 민감도

D 는 창 144에서 최고(0.941)이고 창 256에서 거의 같다(0.936). 창 64에서는 0.854 로 떨어진다 —
짧은 창에서는 위상을 펼칠 구간이 짧아 추정이 불안정하다.

### 5.5 `05_visualize/P2_phase/phase_portrait_lag1` — A-6 설명용 그림
- 가로 = `e(t)` (kg), 세로 = `e(t + 0.109 s)` (kg). **Δt = 1 샘플** (승인 #7).
- 점 색 = 라벨 (주황 transient / 파랑 steady / 회색 ambiguous). 회색 가는 선 = 시간 순서 궤적.
- 패널 7개 = 속도 50 → 200 mm/s. run 앞부분 400시점만 그린다 (과도가 run 앞쪽에 몰려 있다).
- 축 비율을 1:1 로 고정했다 — 대각선에서 얼마나 벗어나는지가 그림의 요점이기 때문이다.
- 읽는 법: **steady(파랑)는 원점 근처에 뭉치고, transient(주황)는 대각선을 따라 음의 방향으로
  길게 늘어난다.** 궤적이 대각선에 바싹 붙어 있는 것은 lag-1 자기상관이 0.85로 높기 때문이고,
  이는 과도가 **충격이 아니라 느린 처짐**임을 보여준다. 고속일수록 주황 구름이 더 멀리 뻗는다
  (처짐이 −0.23 → −0.46 kg 로 커진다).
