## 1. 방법론 — 무엇을 재는가

공정의 물리적 구조에서 나오는 양을 직접 feature 로 쓴다. 제안은 두 갈래였다.

| 제안 feature | 물리적 근거 | 판정 |
|---|---|---|
| **Hilbert energy envelope** (채택 → `env_mean`, `env_std`) | 장력 진동의 **순간 진폭 포락선**. 과도 구간에서 진동 에너지가 크다는 가정 | **채택** |
| Tension-Speed correlation (기각) | 장력과 속도가 함께 움직이면 과도 | **기각** (2.3절) |

포락선은 "진동의 겉모양" 이다. 신호를 해석적 신호로 바꾼 뒤 그 크기를 취하면, 빠른 진동을 벗겨내고
**진폭이 시간에 따라 어떻게 변하는지**만 남는다.

| feature | 정의 | 직관 |
|---|---|---|
| `env_mean` | 창 내 Hilbert 포락선의 평균 | 이 구간의 평균 진동 크기 |
| `env_std` | 창 내 Hilbert 포락선의 표준편차 | 진동 크기 자체가 얼마나 들쭉날쭉한가 |

## 2. 어떻게 적용했는가

### 2.1 산출 절차 (`code/02_features.py`)

```
e(t) = Film Tension #1 (kg) − Film-Tension Setting Value (kg)
  → 시점 t 에서 뒤쪽(causal) 창 x = e[t−W+1 … t]
  → 창 내 평균 제거  x_c = x − mean(x)      ★ 필수 (2.2절)
  → Hilbert 변환     a = hilbert(x_c)        ★ 창 단위로 건다 (causal 유지)
  → 포락선           env = |a|
  → env_mean = mean(env),  env_std = std(env, ddof=1)      단위 kg
```

- **창 단위 Hilbert**: run 전체에 한 번 걸면 미래 시점을 쓰게 되어 causal 하지 않다. 창마다 따로 건다.
  대신 창 양끝 edge effect 가 생기는데, **창 144(15.7 s)는 짧은 창보다 edge 비중이 작다**
  (계획 3.1절의 채택 근거).
- **테이퍼를 쓰지 않는다.** Hann 을 곱하면 창 양끝 진폭이 0으로 눌려 포락선이 왜곡된다.
- 진폭 배율 지수 **1** — `e → c·e` 면 두 feature 모두 `c` 배가 된다 (A-5 정규화에서 환산 대상).

### 2.2 평균 제거가 필요한 이유

포락선은 **진동의 크기**를 재는 양이다. 창 안에 DC 성분(평균 오프셋)이 남아 있으면 포락선이
그 오프셋 크기에 지배되어 "진동이 큰가"가 아니라 "오프셋이 큰가"를 재게 된다. 스펙트럼 계열(P1)의
평균 제거와 같은 이유이고, 같은 전처리를 적용했다.

### 2.3 Tension-Speed 상관을 기각한 근거 (계획 3.1절)

| # | 근거 |
|---|---|
| 1 | **단일 신호 제약**(계획 0.1절, 사용자 확정). `Film Tension #1` 하나만 쓰기로 했으므로 속도 계열을 feature 입력으로 쓸 수 없다 |
| 2 | `Web Speed setting value` 는 **run 내 상수**다. 상수와의 상관계수는 분모가 0이라 **정의되지 않는다** |
| 3 | 실측 속도(`Web Current Speed`)도 사용 신호에서 제외됐다 (계획 0.1절) |

설정값(T·R·V)은 **조건 분할과 잔차 정의에만** 쓰고 feature 입력으로는 쓰지 않는다는 것이 범위
확정 사항이다.

### 2.4 임의로 정한 값

| 값 | 설정 | 근거 |
|---|---|---|
| 창 단위 Hilbert | 창마다 따로 | causal 유지 |
| 테이퍼 | 없음 | 포락선 왜곡 방지 |
| 평균 제거 | 적용 | 2.2절 |

## 3. 결과 해석

### 3.1 식별력 D 는 최상위권인데 전이성 T 는 중하위다

| feature | D(W64) | D(W144) | D(W256) | T(tension) | T(final_test) |
|---|---|---|---|---|---|
| `env_mean` | 0.881 | **0.976** | 0.953 | 0.632 | 0.579 |
| `env_std` | 0.885 | 0.958 | 0.923 | 0.622 | 0.706 |

- **`env_mean` 의 D 0.976 은 16개 중 2위다** (1위 `movmean_abs_e` 0.995). 조건 **안에서는** 거의
  완벽하게 가른다.
- 그런데 T(final_test)는 0.579 로 하위권이다. 기준점 F0(0.541)을 겨우 넘는다.
- **`env_std` 가 `env_mean` 보다 T 가 높다**(0.706 vs 0.579). 평균 크기보다 **크기의 변동**이
  조건을 덜 탄다는 뜻이다.

이 계열은 "D 높고 T 낮음" 의 전형적인 사례다 — **조건별 재보정이 필요한 feature** 로 분류된다
(계획 4.2절의 채택 기준).

### 3.2 증분 기여도 — **둘 다 F0 를 악화시킨다**

| 추가 | ΔT(tension) | ΔT(final_test) |
|---|---|---|
| `env_mean` | **−0.0723** | **−0.1162** |
| `env_std` | −0.0234 | −0.0540 |

`env_mean` 의 ΔT(final_test) −0.1162 는 14개 후보 중 **두 번째로 나쁘다**
(최악은 P5 의 `movmean_abs_e` −0.1167). **진폭을 재는 계열(P4·P5)은 7종이 전부 음수**이고,
모양·주파수를 재는 계열(P1·P3)은 6종이 전부 양수다. 이유:

- 포락선 평균은 `movstd` 와 **같은 것을 재고 있다** — 둘 다 "창 안의 진동이 얼마나 큰가" 다.
  `_cross/corr_matrix_W144.csv` 에서 진폭 계열끼리 높은 상관으로 묶인다.
- 후단이 **diag GMM** 이라 차원 간 상관을 모델링하지 못한다. 중복 축을 더하면 그 방향의 분산을
  두 번 세게 되어 군집 경계가 나빠진다.

→ **P4 는 전진 선택 후보에서 일찍 탈락한다.** 이 계열의 가치는 "추가 축"이 아니라
"`movstd` 와 같은 정보를 다른 방식으로 확인해 준다"는 데 있다.

### 3.3 조건 정보는 중간 수준이다

| feature | 상태 AUROC | 속도 조건 AUROC | steady 구간만 | 속도 분류 정확도 (우연 0.143) |
|---|---|---|---|---|
| `env_mean` | 0.976 | 0.621 | 0.640 | 0.259 |
| `env_std` | 0.958 | 0.631 | 0.655 | 0.238 |

16개 중 중간이다. 스펙트럼 계열(`spec_centroid` 0.739)이나 `hurst`(0.721)보다 낮고,
`movslope`(0.514)·`half_mean_diff`(0.519)보다는 높다.

진폭 계열이므로 **조건에 따라 값의 절대 크기가 이동한다** — 과도 구간 처짐이 저속 −0.23 kg 에서
고속 −0.46 kg 로 2배 커지는 것이 그대로 반영된다. 이것이 T 가 낮은 직접적 원인이다.

### 3.4 진폭 정규화(A-5)의 영향을 가장 크게 받는 계열이다

두 feature 모두 **진폭 배율 지수 1** 이므로, 좌표를 `e ÷ 설정값` 으로 바꾸면 값이 그대로
`1/설정값` 배가 된다. `_cross/a5_normalization.csv` 에서 F0 의 T(final_test)가
0.541 → **0.762** 로 개선되는 것이 확인됐는데, 같은 기전이 이 계열에도 적용된다.

→ **P4 를 쓸 거라면 진폭 정규화를 먼저 정해야 한다.** 원 좌표(`e`)에서의 낮은 T 가 feature 자체의
한계인지 좌표 선택의 문제인지는 그 다음에 판정할 수 있다.

### 5.1 `03_screening/P4_physical/DT_scatter_W144`
- 가로 = D, 세로 = T. 왼쪽 = 미학습 장력 수준, 오른쪽 = 저속→고속 테스트.
- 검은 가로 점선 = F0 기준점의 T.
- 읽는 법: **P4 두 점은 오른쪽 아래**에 있다 — 가로(D)는 거의 끝까지 가 있는데 세로(T)는 낮다.
  "D 만 보고 고르면 안 된다"는 이 분석의 결론을 가장 잘 보여주는 위치다.

### 5.2 `05_visualize/P4_physical/state_distribution_W144`
- 가로 = feature 값(kg), 세로 = 확률밀도. 파랑 steady / 주황 transient.
- 제목의 `d` 는 Cohen's d — `env_mean` **+1.87**, `env_std` **+2.02**. 둘 다 양수 = transient 쪽이 크다.
- 가로 범위는 0.5–99.5 분위로 잘랐다.
- 읽는 법: 파랑(steady)이 0 근처에 **날카롭게 몰려 있고** 주황(transient)은 오른쪽으로 넓게
  퍼진다. 분포 자체는 잘 갈리는데(D 0.976), 주황 쪽 분포의 **위치가 조건마다 이동**하는 것이
  T 가 낮은 이유다. 그 이동은 `04_overlap/.../state_diff_by_condition.csv` 에서 수치로 확인된다.

### 5.3 `05_visualize/P4_physical/timeline_W144`
- 행 = 원신호 `e` → `env_mean` → `env_std`. 열 = 저속 50 / 고속 200. 배경 = 라벨 구간.
- 읽는 법: 창 144 에서 과도 구간 내내 평평하다(backfill, 한계 L2). 전이 직후 값이 **내려간다**
  (진동 에너지가 줄어든다). **고속 패널에서 전이 전 값이 저속보다 뚜렷이 크다** — 같은
  "transient" 인데 조건에 따라 값의 범위가 다르다는 것이 보인다. 고정 경계를 긋기 어려운 이유다.

### 5.4 `05_visualize/P4_physical/window_separation`
- 가로 = feature 2개, 세로 = D, 막대 3개 = 창 64/144/256. 회색 점선 = 우연 0.5. 세로축 0.5–1.0.
- 읽는 법: 둘 다 창 144에서 최고, 창 256에서 약간 떨어진다. 창 64에서는 0.88 수준으로 낮은데,
  짧은 창에서 Hilbert edge effect 비중이 커지는 것과 일관된다 (계획 3.1절의 채택 근거).

### 5.5 `04_overlap/P4_physical/state_vs_condition_W144`
- 가로 = 조건 AUROC(수준 쌍 평균), 세로 = 상태 AUROC. 왼쪽 장력축 / 오른쪽 속도축.
- 세로 점선 = 조건 우연 수준 0.5.
- 읽는 법: **세로로는 거의 천장(0.96–0.98)인데 가로로도 0.62–0.63** 이다. 상태를 잘 맞히는 만큼
  조건도 어느 정도 맞힌다 — 두 정보가 같은 축에 섞여 있다는 뜻이다.

### 5.6 `04_overlap/_cross/state_diff_by_speed_W144`
- 가로 = 속도 설정(mm/s), 세로 = 상태 평균차 `transient − steady` (kg). 진폭 계열만 그린다
  (단위가 kg 로 같아야 한 그림에 놓을 수 있다).
- 읽는 법: 선이 평탄하면 조건 불변, 기울면 조건 의존. **P4 의 선은 속도에 따라 기운다** —
