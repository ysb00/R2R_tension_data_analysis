## 1. 방법론 — 무엇을 재는가

창 안의 값들이 **정규분포처럼 생겼는지**, 그리고 **시간적으로 얼마나 오래 기억을 갖는지**를 본다.
평균이나 분산이 아니라 **분포의 모양과 상관 구조**를 재므로, 진폭이 조건에 따라 변해도 값이
따라 움직이지 않는다 (진폭 배율 지수 0 — 전부 scale-invariant).

| feature | 정의 | 직관 |
|---|---|---|
| `movkurt` | 창 첨도, **excess 규약** (정규분포 = 0) | 꼬리가 두꺼우면 양수. 드문 큰 이탈이 있다 |
| `movskew` | 창 왜도 | 분포가 한쪽으로 기울어 있는 정도. 처짐 방향이 한쪽이면 0에서 벗어난다 |
| `hurst` | R/S 기반 Hurst 지수 | 0.5 = 무기억(랜덤워크 증분), >0.5 = 추세 지속, <0.5 = 평균회귀 |

## 2. 어떻게 적용했는가

### 2.1 `movkurt` · `movskew` (`code/02_features.py`)

```
시점 t 의 뒤쪽 창 x = e[t−W+1 … t]
  movkurt = scipy.stats.kurtosis(x, fisher=True, bias=True)   # excess, 정규 = 0
  movskew = scipy.stats.skew(x, bias=True)
```

**첨도 규약을 명시한다** (승인 #6). `scipy` 기본값은 **excess**(정규분포 = 0)이고, 제안문이 적은
"3 기준"은 `fisher=False` 규약이다. 두 값은 정확히 3만큼 차이 난다. 본 분석은 전부 **excess** 로
통일했고, 논문 표에도 그렇게 적어야 한다. `bias=True` 도 scipy 기본값(표본 편향 보정 없음)이다.

### 2.2 `hurst` — 고전 R/S 추정

```
시점 t 의 뒤쪽 창 x (길이 W)
  각 블록 척도 n 에 대해:
      창을 길이 n 의 비겹침 블록 ⌊W/n⌋ 개로 나눈다
      블록마다  R = max(cumsum(y − ȳ)) − min(cumsum(y − ȳ))
                S = std(y, ddof=1)
                R/S                      (S = 0 인 블록은 제외)
      (R/S)_n = 유효 블록 평균
  Hurst = log(R/S)_n 을 log(n) 에 회귀한 기울기
```

- **블록 척도**: 창 길이를 2로 계속 나눠 만든다 — `W, W/2, W/4, … ≥ 8`.
  창 64 → {8,16,32,64}, 창 144 → {9,18,36,72,144}, 창 256 → {8,…,256}.
  **나누어떨어지는 척도만 쓰므로 블록 나머지가 생기지 않는다.**
- 최소 블록 길이 **8 샘플은 임의의 값**이다.
- `S = 0` 인 블록(양자화로 완전히 평탄한 구간)은 R/S 가 정의되지 않아 평균에서 뺀다.
- **적합 품질을 함께 저장한다** — `hurst_fit_quality.csv` 의 `fit_r2_mean`, `fit_r2_p05`.

### 2.3 임의로 정한 값

| 값 | 설정 | 근거 |
|---|---|---|
| 첨도 규약 | **excess** (정규 = 0) | 승인 #6 (scipy 기본) |
| R/S 최소 블록 | **8 샘플** | **임의의 값** |
| R/S 블록 척도 | `W, W/2, …` 의 2분할 | 나머지가 생기지 않는 척도만 쓰기 위함 |
| F7 포함 여부 | 포함하되 불안정성 기록 | 승인 #11 |

## 3. 결과 해석

### 3.1 계획 3.1절의 F7 우려는 과했다

계획은 "창 144(=144점)에서 R/S·DFA 추정 분산이 크다" 고 적었으나, **log-log 적합은 안정적이다.**

| 창 | Hurst 평균 | Hurst 표준편차 | 적합 R² (run 평균) | 적합 R² (5분위) |
|---|---|---|---|---|
| 64 | 0.919 | 0.081 | 0.986 | 0.954 |
| 144 | 0.851 | 0.091 | 0.974 | 0.939 |
| 256 | 0.811 | 0.108 | 0.971 | 0.931 |

R² 가 전 구간 0.93 이상이다. Hurst 가 0.8–0.9 로 **1에 가깝다** = 이 신호는 강한 추세 지속성을
가진다 (lag-1 자기상관 0.85와 일관).

### 3.2 같은 계열인데 성능이 극단적으로 갈린다

| feature | D(W64) | D(W144) | D(W256) | T(tension) | T(final_test) |
|---|---|---|---|---|---|
| `hurst` | 0.813 | 0.943 | 0.950 | 0.637 | **0.787** |
| `movkurt` | 0.750 | 0.892 | 0.832 | **0.208** | **0.211** |
| `movskew` | 0.781 | 0.852 | 0.881 | 0.377 | 0.213 |

- **`movkurt`·`movskew` 의 T 는 16개 중 꼴찌 두 자리다.** 0.21 은 non-steady 유병률
  기준선(0.081)보다는 높지만 F0 의 0.541 에 한참 못 미친다. D 는 0.85–0.89 로 멀쩡한데
  T 가 무너진다 — **조건이 바뀌면 분포 모양의 경계가 이동한다**는 뜻이다.
- `hurst` 는 T(final_test) 0.787 로 상위권이고 F0(0.541)을 크게 넘는다.

### 3.3 증분 기여도 — **`hurst` 가 전체 1위다**

F0(`movstd`+`|movslope|`)에 1개씩 더했을 때 (창 144):

| 추가 | ΔT(tension) | ΔT(final_test) | 순위 |
|---|---|---|---|
| **`hurst`** | **+0.0324** | **+0.0074** | 14개 후보 중 **1위** |
| `movskew` | +0.0141 | −0.0007 | 2위 |
| `movkurt` | +0.0048 | −0.0013 | 6위 |

**P3 도 세 feature 전부 ΔT(tension) > 0 이다** — P1 스펙트럼과 함께 전원 양수인 두 계열이다.
진폭을 재는 P4·P5 가 전원 음수인 것과 대조된다 (`movstd` 가 이미 진폭을 담당하므로 중복이다).

→ **전진 선택이 `hurst` 를 3번째 축으로 채택했다** (`_cross/forward_selection.csv`):

| 차원 | 추가 | T(tension) | T(final_test) | ΔT | 판정 |
|---|---|---|---|---|---|
| 2 | F0 | 0.6081 | 0.5414 | – | 기준점 |
| 3 | **`hurst`** | 0.6405 | 0.5488 | **+0.0324** | **채택** |
| 4 | `spec_rolloff85` | 0.6449 | – | +0.0044 | 중단 (기준 0.005 미달) |

**최종 선택 집합 = `movstd` + `|movslope|` + `hurst` (3차원).** 이 계열이 선택된 유일한 추가 축을
제공했다.

주목할 점: `movkurt`·`movskew` 는 단독 T 가 최악인데도 **증분은 양수**다. 단독 성능과 증분
기여도는 다른 질문이라는 것을 보여주는 사례다 (P2 는 정반대 — 단독 1위인데 증분 0).

### 3.4 조건 정보 — `hurst` 가 문제다

| feature | 상태 AUROC | 속도 조건 AUROC | steady 구간만 | 속도 분류 정확도 (우연 0.143) | `abs_cv` |
|---|---|---|---|---|---|
| `hurst` | 0.943 | **0.721** | 0.770 | 0.323 | 0.60 |
| `movkurt` | 0.892 | 0.571 | 0.557 | 0.174 | **2.33** |
| `movskew` | 0.852 | 0.522 | 0.548 | 0.174 | **2.19** |

- **`hurst` 는 조건 식별력 2위다** (1위 `spec_centroid` 0.739). 전진 선택이 고른 축이 하필
  조건 정보를 많이 담은 축이다 — **조건 불변화(적대적 제거)를 택하면 선택한 feature 가 먼저
  지워진다.** CoST 변형 설계에서 반드시 고려해야 한다.
- `movkurt`·`movskew` 는 조건 AUROC 가 0.52–0.57 로 거의 우연 수준이다. 조건을 전혀 못 맞힌다.
  그런데 `abs_cv` 가 2.2–2.3 으로 16개 중 가장 크다 — **상태 평균차의 크기가 조건마다 들쭉날쭉**
  하다는 뜻이고, 이것이 T 가 무너지는 이유로 보인다.

### 5.2 `05_visualize/P3_nonstationarity/state_distribution_W144`
- 가로 = feature 값(무차원), 세로 = 확률밀도. 파랑 steady / 주황 transient.
- 제목의 `d` 는 Cohen's d. 이 계열은 **부호가 갈린다** — `movkurt` **−0.46**(transient 쪽이 작다),

- 읽는 법: `movkurt`·`movskew` 는 두 분포가 **크게 겹친다** — D 는 0.85 수준인데 분포가 겹치는 것은
  run 안에서는 갈리지만 전체를 모으면 run 마다 위치가 달라 섞인다는 뜻이다. **T 붕괴의 시각적 근거다.**

### 5.3 `05_visualize/P3_nonstationarity/timeline_W144`
- 행 = 원신호 `e` → `movkurt` → `movskew` → `hurst`. 열 = 저속 50 / 고속 200. 배경 = 라벨 구간.

  경계를 긋기 어렵다는 것이 그림에서도 보인다.

### 5.5 `04_overlap/P3_nonstationarity/state_vs_condition_W144`
- 가로 = 조건 AUROC(수준 쌍 평균), 세로 = 상태 AUROC. 왼쪽 장력축 / 오른쪽 속도축.
