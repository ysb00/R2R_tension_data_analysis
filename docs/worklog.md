### 구현하면서 정한 값 (전부 코드 주석에 "임의의 값" 표기)
- `movmad` = 창 평균에 대한 **평균**절대편차. 중위절대편차는 양자화(0.010 kg) 때문에 값이
  몇 단계로만 변해 feature 로 못 쓴다.
- F7 블록 척도 = `W, W/2, W/4, … ≥ 8`. 나누어떨어지는 척도만 써서 블록 나머지를 없앴다.
- A-4 조건 식별력의 주 지표를 **평균 쌍별 AUROC** 로 두었다. 계획이 적은 "정확도" 는 우연 수준이
  축마다 달라(0.200 / 0.143) 상태 AUROC 와 같은 산점도에 놓을 수 없다. 정확도도 함께 낸다.
- 전진 선택 기준 fold 묶음 = **장력축 CV**. 속도축 `final_test` 로 고르면 B 의 최종 테스트
  집합에 선택이 새어 들어간다. `final_test` 는 고른 뒤 확인용으로만 본다.
- A-6 spectrogram 분석창 = 64 샘플. 주 창 144 를 쓰면 과도 구간이 창 하나에 통째로 들어가
  전이가 보이지 않는다 (설명용 그림의 목적이 성립하지 않는다).
- A-5 는 feature 를 다시 산출하지 않고 `feature_scaling.csv` 의 **진폭 배율 지수**로 환산했다.
