### 정정한 판단
- 초안에서 **"창 144는 210 run 중 156개의 transient 를 전멸시키므로 사용 불가"** 라고 적었다.
  이는 "창을 완전히 채운 시점부터 산출"이라는 **내 가정**에 의존한 것이고, **B 규약에서는 성립하지 않는다.**
  B는 `01_stat_ssd.py:117-118` 에서 앞 `w−1` 시점을 **첫 완전창 값으로 backfill** 하고
  CoST 는 `SLIDING_PADDING = W−1`·`CASUAL = True` 로 좌측 패딩한다. **시점을 버리지 않는다.**
  → **창 144를 주 설정으로 승계**하고, 민감도 격자에 64(B 통계 baseline 의 `fixed` 값)를 넣었다.
- 다만 backfill 의 성질상 **창 144에서는 `k ≤ 142` 가 모두 같은 feature 값**을 받는다. G5 와 합치면
  **이동창 통계 feature 는 transient 내부에서 상수**다 → 한계 L2 로 기록하고 창 64 와 대조해 분리한다.
- B 저장소의 C 실험 완료 여부는 **본 분석의 전제가 아니다**(사용자 지시). CoST 가 일관 1위라는 결론만 승계한다.
