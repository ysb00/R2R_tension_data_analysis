- `N_GMM_COMPONENTS = 2`, `GMM_COVARIANCE_TYPE = 'diag'`, 나머지는 sklearn 기본값.

  (기존 `feature_analysis_plan.md` 의 "hop = L/2, 창 내 라벨이 모두 같을 때만 사용" 방식은 후단과 맞지 않으므로 쓰지 않는다.)
- 후단이 **축정렬 2-가우시안**이므로, 제안 표현의 요건은 "분리된다"가 아니라
  **"저속에서 적합한 축정렬 2-가우시안 경계가 고속에서도 유효하다"** 이다.

## 3. 1단계 분석 설계

### 3.1 A-1. 회전 둘레 재산출 (B의 F4)

저속 90 run 만으로 회전 1차 성분을 역산한다. 방법은 B `code/02_eda/01_rotation_frequency.py` 와 동일하게 둔다
(평균 제거 → Hann 창 → 단측 파워 스펙트럼 → 탐색 대역에서 최대 주파수 → `C = V / f_peak`).

- 산출: `C_low` (90 run 평균·표준편차), 속도별 중앙값, B의 783.5 mm 와의 차이.
- `C_low` 가 이후 **모든 거리축 변환의 유일한 물리 상수**이고, 라벨 없이 설정값과 신호만으로 나온다.
- 라벨 없이 run **전체** 신호를 쓰므로 R1 위반이 아니고, 저속 run 만 쓰므로 R5 위반도 아니다.

### 3.2 A-2. P1 — 시간축 vs 거리축(차수축)

**아이디어**: 시간축 대신 **필름 이동 거리축** `s = V·t` 를 쓰고, 창을 **회전 1주기 = C_low mm** 로 고정한 뒤
고정 샘플 수 N 으로 리샘플한다. 그러면 회전 1차 성분이 **모든 속도에서 차수 1** 에 놓이고,
SFD 의 bin 별 가중치와 TFD 의 커널 스케일이 속도 간 전이된다.

```
W(V) = ceil( fs · C_low / V )      회전 1주기에 해당하는 시간축 샘플 수 (= B의 규칙 1b)
각 시점 k 에서 직전 W(V) 샘플을 N 샘플로 선형 리샘플 (causal)
-> rFFT -> 차수 1,2,3,… 축의 스펙트럼
```

- N = 144 로 두면 V=50 은 사실상 무보간이다 (Δs = C_low/144 ≈ 5.44 mm, V=50 의 샘플당 이동 거리 50×0.109 = 5.45 mm).
- **유효 차수 상한이 속도에 의해 제한된다**: 시간축 Nyquist 가 고정이므로 사용 가능한 최대 차수는 `W(V)/2` 다.

  | V (mm/s) | 50 | 75 | 100 | 125 | 150 | 175 | 200 |
  |---|---|---|---|---|---|---|---|
  | `W(V)` (samples) | 144 | 96 | 72 | 58 | 48 | 42 | 36 |
  | 최대 유효 차수 | 72 | 48 | 36 | 29 | 24 | 21 | **18** |

  테스트 최고 속도(200)까지 전이시키려면 **차수 1–18 만 유효**하다. 이 값은 설정값·fs·`C_low` 만으로
  나오므로 고속 신호를 보지 않는다 (R5 준수). 차수 18 초과 성분은 보간 산물이므로 설계에 쓰지 않는다.

**측정** (라벨 불필요): 속도가 바뀔 때 스펙트럼 **형상**이 얼마나 달라지는가를 시간축과 차수축에서 비교한다.

| 산출 | 내용 |
|---|---|
| 속도별 평균 정규화 스펙트럼 | 시간축(Hz) / 차수축 두 가지 |
| 속도쌍 간 스펙트럼 거리 | (50,75), (50,100), (75,100) 3쌍. **차수축에서 작아지면 P1 채택** |
| f_peak 위치의 변동계수 | 시간축에서는 속도에 따라 이동, 차수축에서는 차수 1 고정이어야 한다 (보조 근거) |

### 3.3 A-3. S–C 지표 — 분리력과 조건 전이성

특징마다 **두 수치의 쌍**을 산출한다. 둘 다 라벨을 쓰지 않는다.

| 지표 | 정의 | 후단과의 관계 |
|---|---|---|
| **S (분리력)** | 1.1절 후단과 **같은 구조**(StandardScaler + 2군집 diag GMM)를 적합하고, 두 성분 평균 간 거리를 분리도로 쓴다 | 후단이 찾을 수 있는 분리만 센다 |
| **C (조건 전이성)** | ① **군집 경계 이동량**: V ∈ {50,75} 로 적합한 후단을 V = 100 에 적용했을 때, V = 100 으로 직접 적합한 결과와의 군집 할당 불일치율 ② **조건 예측 가능도**: 특징에서 V(또는 T)를 맞히는 정확도 | ①이 저속 안의 외삽 프록시다 |

**S 높고 C 낮은 좌표계**가 채택된다. S–C 산점도가 1단계의 핵심 그림이다.

### 3.4 A-4. P2 — 진폭 좌표 3종

| 좌표 | 근거 | 사전 예측 (1.2절) |
|---|---|---|
| `e` (kg) | 설정값 추종 잔차. 현재 B의 전 방법이 쓰는 입력 | 장력축에서 가장 불변 |
| `e ÷ 설정값` | 비율 잔차 | **악화 예상** — steady 변동이 설정값에 평탄하므로 7 kg 에서 2.3배 축소된다 |
| `e ÷ MAD(run)` | run 전체 e 의 중위절대편차로 무차원화. 조건마다 자동 적응 | 속도축에서 C 를 낮추지만 S 도 낮출 수 있다 |

- `MAD(run)` 은 "steady 가 run 의 대부분(85.8%)" 이라는 **분포 가정**을 쓴다. 위치 가정(R2 금지)은 아니지만
  **별도 승인이 필요하다** (5절 #8). 또한 run 전체를 보므로 **causal 하지 않다** — 온라인 적용 가능성의 한계로 기록한다.

### 3.5 A-5. 사후 감사 (라벨 사용)

A-1~A-4 의 결론을 **동결한 뒤** 별도 스크립트에서만 라벨을 읽어, label-free 지표(S·C)가 라벨 기준(AUROC·오염률)과
같은 순서를 주는지 확인한다. **저속 90 run 에서만** 수행한다. 설계는 되돌리지 않는다 (확정 1번).

라벨 격리는 코드 구조로 보장한다: A-1~A-4 스크립트는 `usecols` 에서 `Trigger 4` 를 제외하고,
감사 스크립트 1개만 라벨을 읽는다 (B의 G2 점검 방식과 동일).
