## 0. 이 문서의 역할

`research_plan.md` 3절은 **P1(거리 좌표계)·P2(진폭 좌표)** 를 1단계로 정했다. 그런데 P1은

핵심 가능성 하나를 미리 적어 둔다: **신호가 두 성분이고 각자 좌표계가 다를 수 있다.**
회전 외란(주기 성분)은 B가 이미 거리축으로 확인했지만(`f_peak ∝ V`), 과도 응답과 광대역 잡음은

## 2. 공통 검정 템플릿 — 좌표계 판정

아이디어 4.2·4.3과 5.2는 서로 다른 현상을 보지만 **검정 구조가 같다.** 어떤 길이 척도 L을
측정해 시간(s)과 거리(mm)로 각각 환산하고, 속도 3수준 간 변동계수(CV)를 비교한다.

귀무 모델이 기대 CV를 준다. V ∈ {50, 75, 100} 이므로:

| 실제 좌표계 | 시간 기준 CV | 거리 기준 CV | 유도 |
|---|---|---|---|
| **시간축** (L_t = const) | ≈ 0 | **0.33** | L_s ∝ {50, 75, 100} → 평균 75, 표준편차 25 |
| **거리축** (L_s = const) | **0.35** | ≈ 0 | L_t ∝ {1/50, 1/75, 1/100} → CV 0.35 |
| 둘 다 아니다 | 0.3 내외 이상 | 0.3 내외 이상 | 속도 단독으로 설명되지 않음 |

**판정 규칙**: 한쪽 CV가 0.3 내외이고 다른 쪽이 0.1 미만이면 좌표계가 갈린다.
둘 다 0.2–0.4 면 V × T 2원 분석으로 넘어간다.

이 기준은 **유도값이므로 임의의 값이 아니다.** 속도 3수준이라는 제약에서 자동으로 나온다.

### 4.1 [1순위 · A6] 회전 외란의 고조파 구조

**의미.** B는 회전 1차 성분만 측정하고 "고조파(2f, 3f)나 다른 롤러의 성분이 섞여 있을 수 있고
확인하지 않았다"를 한계 #4로 남겼다. 고조파가 있으면 두 가지가 동시에 결정된다 — **R1 차수 대역의
경계**와, **4.2에서 노치로 제거할 대상**이다. 그래서 1순위다. 이것을 모르면 4.2가 "잡음의 상관 길이"를
재는 것이 아니라 "남은 주기 성분의 주기"를 재게 된다.

| 단계 | 내용 |
|---|---|
| 1 | run별 e → 평균 제거 → Hann 창 → 단측 파워 스펙트럼 (A-1과 동일 방법) |
| 2 | `f_rot = V / C_low` 계산. **설정값과 `C_low` 만 쓴다** — 신호에서 peak 을 찾지 않으므로 순환 논리가 아니다 |
| 3 | 차수 m = 1…18 에 대해 `f = m·f_rot` 근방 ±Δ bin 의 파워 `P_m` 추출 |
| 4 | 국소 배경 `B_m` = 인접 대역 파워의 중위수. **돌출도 = P_m / B_m** |
| 5 | 90 run 의 차수별 돌출도 분포 → 임계를 넘는 차수 목록 |
| 6 | 속도 3수준에서 **같은 차수가 돌출하는지** 확인 (일관성이 회전 기원의 근거) |

- **판정**: 돌출도가 임계를 넘고 속도 3수준에서 일관된 차수 = 실재하는 고조파.
- **해상도 점검**: `fs/n = 0.0072 Hz`, V=50 의 `f_rot ≈ 0.064 Hz` → 차수 1이 bin 약 9이고 차수 간격도 약 9 bin 이므로 분리된다. 차수 18 at V=100 은 약 2.3 Hz 로 Nyquist 안이다.
- **산출물**: 차수별 돌출도 profile plot (가로 차수 1–18, 세로 돌출도, 속도별 3곡선), 차수별 통계 csv
- **바꾸는 결정**: R1 차수 대역 경계 (차수 1 단독이면 대역 2개, 1·2·3이면 3개). 4.2의 노치 대상
- **임의의 값**: Δ(bin 폭), 돌출 임계, 배경 대역 정의
- **한계**: 차수 상한 18은 V=200 의 `W(V)/2` 에서 온다(`research_plan.md` 3.2). 그보다 높은 차수는 고속에서 전이될 수 없으므로 보지 않는다

### 4.2 [2순위 · A4] 광대역 성분의 자기상관 길이 — 좌표계 판정 ①

**의미.** P1의 핵심 가정("속도가 바뀌어도 거리축에서는 동특성이 같다")을 **스펙트럼 형상 논증보다
직접** 판정한다. B가 측정한 steady 잡음 자기상관(lag 1: 0.85, lag 2: 0.62, lag 5: 0.36)은 주기 성분과
광대역 성분이 섞인 값이다. 4.1로 주기 성분을 제거한 뒤 남는 성분의 상관 길이가
**거리에서 일정하면 P1 채택의 가장 강한 근거**가 되고, **시간에서 일정하면 TFD 커널을 샘플 단위로
두는 현재 CoST 구조가 오히려 맞다**는 뜻이 된다.

| 단계 | 내용 |
|---|---|
| 1 | run별 e 에서 평균 제거. 4.1에서 확인된 차수(1차 + 고조파)를 **노치 제거**. 주파수는 `V/C_low` 유도값 |
| 2 | 잔여 성분의 자기상관함수 ρ(lag) 를 **run 전체**에서 산출. 구간을 자르지 않는다 (1절). 과도 구간이 전체의 약 8%(라벨 0 중앙값 101 / run 1288)임을 결과에 명시 |
| 3 | 상관 길이 L = ρ(lag) 가 1/e 로 떨어지는 첫 lag (샘플) |
| 4 | 환산: `L_t = L × 0.109` s, `L_s = L × 0.109 × V` mm |
| 5 | 속도별 평균·CV 를 두 척도에서 산출 → **2절 표로 판정** |

- **산출물**: run별 L (샘플/s/mm) csv, 속도별 평균·CV 표, plot 2패널 (가로 V, 세로 L — 왼쪽 s, 오른쪽 mm, 각 패널에 전체 평균 수평선)
- **바꾸는 결정**: TFD 커널 스케일(S1)을 샘플 단위로 둘지 거리 단위로 둘지. 거리축이면 CoST 커널 [1, 2, …, 128] 을 거리 단위로 재정의한다
- **임의의 값**: 상관 길이 정의(1/e vs 1/2 vs 첫 영교차), 노치 폭
- **한계**: 과도 구간 8%가 포함된다. 4.3의 과도 지속 길이로 보정한 버전을 함께 산출해 민감도를 본다

### 4.3 [3순위 · A5] 과도 응답 지속 길이 — 좌표계 판정 ②

**의미.** 1단계 설계의 **분기점**이다. 4.2(광대역)와 이 항목(과도)의 좌표계가 주기 성분(거리축 확인됨)과
다르면, P1을 단일 거리축으로 둘 수 없다. B가 이미 "안정화 시간 근거는 일부 불일치(U자형)"라고 적었으므로
**갈릴 가능성이 상당하다.** 갈리면 `research_plan.md` 3절을 이중 좌표계로 다시 써야 한다.

난점은 **라벨 없이 과도를 재는 것**이다. 위치를 쓰지 않는 정의를 주 분석으로 둔다.

| 단계 | 내용 |
|---|---|
| 1 | run별 `MAD(e)` 산출 (run 전체 중위절대편차 — **분포 가정**이지 위치 가정이 아니다) |
| 2 | **주 정의**: `\|e\| > κ·MAD(e)` 인 샘플의 **총 개수** `N_tr`. 어디에 있는지 묻지 않고 몇 개인지만 세므로 위치를 전혀 쓰지 않는다 |
| 3 | 환산: 시간 `N_tr × 0.109` s, 거리 `N_tr × 0.109 × V` mm → **2절 표로 판정** |
| 4 | **보조 정의**: `\|e\|` 의 이동 95분위가 `κ·MAD` 아래로 처음 내려가는 시점 τ. 이쪽은 "과도가 앞에 있다"는 **위치 가정**을 쓰므로 보조로만 쓰고 그 사실을 명시 |
| 5 | 주·보조 정의의 결론이 같은지 확인. 다르면 주 정의를 채택하고 차이를 기록 |
| 6 | 두 척도 CV 가 모두 크면 **V × T heatmap** 으로 확장 (B의 U자형 불일치 재현 여부) |

- **산출물**: run별 `N_tr`·τ csv, 속도별 CV 표, V × T heatmap, plot 2패널
- **바꾸는 결정**: **단일 좌표계 vs 이중 좌표계.** 창 길이 규칙(규칙 1b)이 주기 근거만으로 유지되는지 여부
- **임의의 값**: κ, 이동 분위 창 길이, 분위 수준(95)
- **한계**: 저속에 재불안정 run 2개(`T5_R6_V50`, `T6_R7_V50`)가 있어 `N_tr` 에 두 구간이 합산된다 — 별도 표시한다

### 4.4 [4순위 · A8] 차수 스펙트럼 추정 품질 vs 창 길이

**의미.** `research_plan.md` 5절의 **#2(N = 144)** 와 **#3(차수 1–18)** 을 임의값에서 근거값으로 바꾼다.
문제는 구체적이다 — V=200 에서 회전 1주기가 **36 샘플뿐**인데, 그 36 샘플로 차수 1–18 을 추정해야 한다.
추정 분산이 너무 크면 "창 = 회전 1주기" 규칙 자체가 고속에서 무의미해진다.

| 단계 | 내용 |
|---|---|
| 1 | 창 정의 3종: **W1** 회전 1주기 고정 `ceil(fs·C_low/V)` / **W2** 고정 샘플 수 144 / **W3** 고정 회전 수 R 주기, R ∈ {1, 2, 3, 4} |
| 2 | 각 run 에서 causal 이동창으로 차수 스펙트럼(1–18) 추정 |
| 3 | **재현성**: 같은 run 안 인접 창들의 추정값 상대표준편차 |
| 4 | **편향**: 가장 긴 창(R=4)의 추정을 기준으로 짧은 창 추정의 편차 |
| 5 | 차수별로 상대표준편차가 허용 수준 이하가 되는 **최소 회전 수 R\*** 결정 |
| 6 | R\* 를 고속에 적용: V=200 에서 창 = `R* × 36` 샘플 = `R* × 3.9` s. 이 값이 B의 창 상한 근거(진입 지연 ∝ 창 길이, W=512 에서 +35.5 s)와 충돌하는지 확인 |

- **산출물**: (창 종류 × 차수) 상대표준편차 heatmap, R\* 결정 표, 창 길이 vs 진입 지연 trade-off 표
- **바꾸는 결정**: N과 차수 상한. **R\* > 1 이면 "창 = 회전 1주기" 규칙이 수정된다** — 규칙 1b 의 하한 논리(1주기 미만이면 진동이 추세로 보인다)와, 추정 분산 하한이 서로 다른 값을 요구할 수 있다
- **임의의 값**: 허용 상대표준편차 수준
- **한계**: 고속 창(36 샘플)의 추정 품질을 **저속 데이터로 모의**한다(저속 run 을 36 샘플 창으로 자름). 실제 고속 신호의 SNR 과 다를 수 있다

### 4.5 [5순위 · A7] 회전 외란 진폭의 속도 의존성 — 봉인된 예측

**의미.** `research_plan.md` 1.2절은 "진폭 축은 순방향 외삽이라 안전"으로 판단했다. 그 판단을 뒤집을
수 있는 유일한 기전이 이것이다 — 회전 외란 진폭이 속도와 함께 커지면, **고속의 steady 창 안에
저속 기준으로는 미안정처럼 보이는 주기 성분**이 들어온다.

결론은 고속에서만 확인되므로, 저속에서 예측을 만들어 **봉인하고** 최종 평가 때 개봉한다.
사전 등록(preregistration) 형태라 논문에서 강하다.

| 단계 | 내용 |
|---|---|
| 1 | 4.1의 차수 1 성분에서 run별 진폭 `a₁` (kg) 추출 |
| 2 | 속도 3수준의 `a₁` 평균 → `log a₁ vs log V` 회귀 → 기울기 β와 신뢰구간 |
| 3 | V = 125, 150, 175, 200 의 `a₁` **예측값과 예측구간** 산출 |
| 4 | 예측값을 저속 steady 변동(약 0.038 kg)과 저속 미안정 처짐(약 −0.23 kg)과 비교 |
| 5 | 예측을 `outputs/` 에 csv 로 **고정 저장**. 고속 실측과의 대조는 **최종 평가 단계에서만** |

- **판정**: β > 0 이고 V=200 예측 진폭이 steady 변동에 가까워지면 **P2에서 진폭 정규화(`e ÷ MAD(run)`)가 필요**해진다
- **산출물**: 속도별 `a₁` csv, 회귀 plot + 외삽 예측구간(고속 구간은 예측만, 실측점 없음), 봉인 예측 csv
- **임의의 값**: 없음 (회귀 형태 선택 제외)
- **한계**: 저속 3수준(2배 범위)에서 4배 외삽한다. 예측구간이 넓을 것이고, 그 폭 자체를 결과로 보고한다

### 4.6 [6순위 · A11] run 내 변동 vs 조건 간 변동

**의미.** 조건당 run 이 1개다(B의 **L5**). 따라서 "속도 100 에서 이 값이 크다"가 **조건 효과**인지
**그 run 하나의 특성**인지 원리적으로 구분되지 않을 수 있다. 이 표는 성능을 올리지 않지만,
**다른 모든 조건별 주장의 신뢰구간**을 정한다. 심사에서 가장 먼저 찔릴 지점이다.

| 단계 | 내용 |
|---|---|
| 1 | 관심 통계량 θ 목록 고정: 차수 1 진폭(4.5), 상관 길이(4.2), `MAD(e)`, 과도 지속 길이(4.3) |
| 2 | run 을 겹치지 않는 블록 B개로 나눠 블록별 θ 산출 → **run 내 분산** σ²_within (블록 평균을 쓰므로 위치를 쓰지 않는다) |
| 3 | 같은 (V, T) 조건군 안에서 run 간 θ 분산 → **run 간 분산** σ²_between (저속에서 (V,T) 조합당 R 만 다른 6 run) |
| 4 | `ICC = σ²_between / (σ²_between + σ²_within)` |
| 5 | ICC 가 작은 θ 는 "조건 효과가 run 내 변동에 묻힌다"로 판정 → 그 θ 에 기반한 조건별 주장은 하지 않는다 |

- **산출물**: θ별 분산 분해 표, ICC. 다른 결과 문서의 각주로 인용
- **임의의 값**: 블록 수 B, θ 목록
- **한계**: 과도 구간이 첫 블록에 몰려 σ²_within 을 키운다. 4.3의 `N_tr` 로 과도를 제외한 버전을 함께 산출한다
